## The narrative arc they build

The five seed scenarios form a spine:

1. **003** — the three-state physics (annihilation leaves a body).
2. **001** — the first meeting that produces the plane's substance.
3. **002** — the blindness that makes the plane grey.
4. **005** — the price Time extracts for revealing color.
5. **004** — the Council that re-opens the cycle.

A scene can be built from one scenario, or from a crossing of two (e.g. a scene
that is both `002` blindness and `005` time-price).

## How to add a scenario

1. Write it as `scn-###-short-name.md` in this folder.
2. Ground it in a reference in `04-references/`.
3. Tag it with axis + mechanic.
4. Add it to this index.
5. Log the canon decision in `debate-log.md`.

## Scene-assembly rule (from Luka)

> "A game design are scenes, we should make the scenes mimic the development
> but make it more appealing."

Scenes are the surface; scenarios are the load-bearing structure beneath. The
development of the game should *mimic* the development of the mythos — from
first contact to the eternal cycle.
