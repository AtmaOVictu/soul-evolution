  responsibility) is **good/better**; a negative κ (fear, greed, apathy) is a
  **detriment**. The game's alignment is a running value, not a static choice.
- **The cycle is the formula.** O→∆→1→Ω→repeat is the eternal cycle
  (war → grey → council → rebirth) given as arithmetic. Each phase carries a

- **"Return to O"** — the cycle always returns to the field (O≡0). This is the
  ring-closing (∮) from the topology.
