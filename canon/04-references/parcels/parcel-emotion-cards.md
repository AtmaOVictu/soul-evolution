## The common directive (all cards)

> "The agent does not escalate (ALERT), performs a NE-side (1–2 rounds), then chooses a transition."

## Key connections

- **The emotions are phoneme-encoded.** Each emotion has a distinctive IPA core
  (e.g. Anger = stops /p t k/, Love = open vowels /a o u m n l w/, Fear =
  fricatives /h n x/ + silence). This extends the Phonetic Word / Phoneme-OSEBNIK
  into the emotional register — emotions are audible, not just felt.
- **The DA/NE pair recurs.** Each emotion has a logic-of-flow (DA) and an
  illogic-of-break (NE) — the same DA/NE antinom as Colored Agents and Apd Kocka.
  The "Mogone" generativity matches Colored Agents' Mogone.
- **The non-escalation directive is the ethics doctrine.** The agent does not
  escalate (ALERT) — it performs the NE-side (breaks) then chooses a transition.
  This is the σ-protocol / no-escalation ethic applied to emotion.
- **Gray3 codes encode the emotions.** Each emotion has a 3-bit Gray code — a
  possible binary encoding for the game's emotional state.

## Potentiality / Reliability / Repetition

- **Potentiality:** the emotion cards give the game an **audible emotion system** —

  Gray3 code. The player's emotions are speakable and encodable.
