## The four metrics (the soul's operational readout)

- **align(Q*,R)** = 0.4·Sem + 0.4·Ont + 0.2·Eff; threshold **ρ_min = 0.70**
- **noise(R)** = 1 − |Carriers|/|Tokens|; threshold **ε_noise = 0.10**; |Carriers| ∈ {1..5}
- **Δ** = dist(S_pre,S_post)/dist_max; threshold **Δ_min = 0.01**
- **risk** = α_β·β + α_θ·θ_ost + α_str·θ_tox − α_R·Eff(R); safe **θ_safe = 0.60**

## The therapeutic modules

- **JESIK/ANJE** (healing speech): DAJ(Z, B_ost, Q*, R, ⧗L) — healing iff align ≥ 0.70 ∧ θ_tox < 0.60.
- **STRUP↔ZDRAVILO** (poison↔remedy): θ_tox = γ_frek·f + γ_int·i + γ_izol·z; protocol = SECIRAJ ψ⁻ → Θ → micro-ritual ≤ 2m → σ + ORIENT.
- **AGENT_METRIKA**: integrity = 1 − dist(R_promised, R_observed); mask = min(1, κ_stil·noise + κ_odlog·lag); loyalty update with hysteresis.

## The canonical PASS tests

1. align ≥ 0.70 · 2. noise ≤ 0.10 and 1 ≤ |Carriers| ≤ 5 · 3. Δ ≥ 0.01 or Eff(R) = 1 · 4. risk < 0.60 or σ/↺ executed.
