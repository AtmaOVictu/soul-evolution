## How to add a parcel

1. Read the source document.
2. Summarize it (what it is, what it argues).
3. Parcel the usable concepts into a table mapped to canon (mythos/operators/
   axes/systems/scenarios).
4. Translate the load-bearing Slovenian lines.
5. Note any open canon question it raises.
6. Log the canon decision in `debate-log.md`.
