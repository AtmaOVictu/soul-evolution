# 06 — The Systems (entity-interactive)

> **STATUS: OPEN FOR REVIEW** — v0.01. The principle: every entity has a
> designated treasure/currency (`05-treasures.md`) **and** a system the player
> can interact with. The treasury is *what* each holds; the system is *how* the
> player engages it. Paired with the rule "new concepts get new systems" — each
> entity's system is its own, not a repurposing of another's.

## The principle

Every entity of the plane exposes a **player-interactive system**. The player
does not just observe the mythos — they *act through* each entity's system. The
windows are the visible surfaces of these systems; the treasury is what flows
through them.

Interacting with an entity's system is how the player constructs the reality
("simulating reality by constructing narratives") — each engagement is an act
that the system receives and the narrator (Time) names.

## The mapping (hypothesis)

| Entity | Treasure | Interactive system | Player can... |
|---|---|---|---|
| **Fire** (Light/White) | revealed light | **Illumination** | fire, charge, reveal |
| **Air** (Dark/Black) | silence | **Concealment / Repulsion** | field-control, ambush, hide |
| **Neutron** (grey) | inertia | **Wreckage** | reclaim (crack open), push |
| **Dust** | formlessness | **Building** | spend dust to shape the soul |
| **Time** | duration | **Trade / Narration** | offer treasure, receive the other's value |
| **Spirit** (both) | shared register | **Harmony** | align both elements, reach the better path |

## How the systems compose

A scene is built from one or more entity-systems. The player's moment-by-moment
interaction is, at root, engagement with these systems:

- **Illumination** (Fire) — the beam: fire to reveal, charge to deepen.
  *(already built in `soul.gd`)*
- **Concealment / Repulsion** (Air) — the force field + dark-zone hiding.
  *(already built — `_update_concealment`, force field)*
- **Wreckage** (Neutron) — the broken shard: reclaim it to feed color, or push
  it. *(not yet built — `CRITICAL_BRIEF.md` §8)*
- **Building** (Dust) — the character-builder: spend dust on the soul.
  *(not yet built — `CRITICAL_BRIEF.md` §9)*
- **Trade / Narration** (Time) — offer your treasure to see the other.
  *(not yet built — the exchange)*
- **Harmony** (Spirit) — harmonize fire and air for the "better" outcome.
  *(not yet built — the alignment doctrine)*

## The rule it enforces

"No new systems" is not an option — a genuinely new entity brings a genuinely
new interactive system. Reusing machinery is allowed only where the *concept*
is genuinely the same (e.g. concealment reused for feat-blindness, because it
*is* reduced perception). But Fire, Air, Neutron, Dust, Time, and Spirit each
own their system.
