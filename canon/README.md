## Purpose

This folder is the **canon** of Soul Evolution — the fixed, referenced body of
mythos, mechanics, and scenarios that the game is built from. It exists so that
multiple agents (Cline, Claude Code, Codex) and humans all work from the *same*
ground truth, instead of each drifting into their own interpretation.

The canon is **not** the game code. It is the **source of meaning** that the
code is meant to express. Scenes in the game are *built from* these scenarios;
they are not the scenarios themselves.

## Scope

- `00-mythos.md` — the master mythos: dark vs sun, fire/air/spirit, Time as
  narrator-trader, the eternal cycle.
- `01-operators.md` — the ontological operators (∇ ¬ ∆ ✡ τ σ) and how they map
  to elements, mechanics, and souls.
- `02-axes.md` — the 12 axes (prehod, beseda, um ... dvom) as realms/scenes.
- `03-scenarios/` — the scenario building-blocks: reusable units of mythos +
  mechanic + image, each grounded in a specific reference.
- `04-references/` — the source texts (from Obsidian + corpus), with Slovenian
  originals and English translations.
- `debate-log.md` — the append-only record of every canon decision (what was
  debated, what was locked, what remains open).

## How scenarios become scenes

A **scenario** is a building-block: a fragment of the mythos with a mechanic
attached and an image. A **scene** is a playable moment assembled from one or
more scenarios. The rule (from Luka): *"a game design are scenes, we should
make the scenes mimic the development but make it more appealing."* So the
scenes are the surface; the scenarios are the load-bearing structure beneath.

## Working rules

1. **Link, don't invent** — every canon claim traces to a reference in
   `04-references/`. If it can't be linked, it's flagged `[OPEN]`, not canon.
2. **Translate, don't lose** — Slovenian originals are preserved; English
   translation is provided. The Slovenian is the soul; English is the voice.
3. **Mark for review** — nothing is locked without a `debate-log` entry.
4. **New systems, not reuse** — a genuinely new concept gets its own system;
   it is not bolted onto an existing one.
5. **The game does not give knowledge lightly** — canon may be opaque. The
   player earns understanding; the docs do not hand it over.
