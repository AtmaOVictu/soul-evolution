# soul-evolution

A Godot 4 game about the eternal war of light and dark souls. When a light soul and a dark soul annihilate each other, they dissolve into color and leave neutral gray behind; souls are reborn into the Great World, and the war continues.

## Contents

- `project.godot` — Godot 4 project file
- `scenes/`, `scripts/`, `shaders/` — game scenes, code and visuals
- `assets/`, `blender/` — assets and 3D sources
- `docs/`, `DESIGN.md`, `CRITICAL_BRIEF.md` — design and direction
- `icon.svg` — project icon
- `LICENSE.md`, `TDM-RESERVATION.md`, `REGISTER-NEIMENOVANIH.jsonl`, `REGISTER-PADCEV.jsonl`, `VBL-10.5.1-KOMPIL-A-DRAFT-NOT-RELEASED.md` — license family

## Run

Open this folder in the Godot 4 editor (Import → select `project.godot`) and run the main scene.
