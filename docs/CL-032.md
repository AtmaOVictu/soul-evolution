# CL-032 — Refactored: Per-Distinction Clarity + World Building

## What changed

Clarity is no longer a single global float. Each distinction is a **DistinctionNode** —
a Node2D with its own local clarity, its own visual state, and its own capacity to react.

The world is not pre-authored. It is grown, one distinction at a time.

## Architecture

```
scripts/ritual/
  events.gd                     # Event Bus — no global clarity, has registry + query
  ritual_state_machine.gd       # FSM spine (unchanged)
  distinction_node.gd           # NEW: a single distinction with own clarity + visuals
  boundary_node.gd              # NEW: auto-generated between paired distinctions
  ref_region.gd                 # NEW: spatial scope frame (CL-034 seed)
  question_prompt.gd            # (unchanged)
  consequence_card.gd           # (unchanged)
  clarity_bar.gd                # REFACTORED: reads aggregate, not global
  distinction_field_ritual.gd   # REFACTORED: spawns DistinctionNodes, not ColorRects
  ritual_loop_starter.gd        # (unchanged)
```

## DistinctionNode lifecycle

Each distinction has its own clarity stage:

```
TENTATIVE (κ=0.05) → DISTINGUISHED (κ=0.15) → SCOPED (κ=0.30)
→ WITNESSED (κ=0.55) → GUARDED (κ=0.75) → SEALED (κ=1.0)
```

Visual states per stage:

| Stage | Visual | Interactive capacity |
|-------|--------|---------------------|
| TENTATIVE | Faint, flickering, barely visible | Can be hovered |
| DISTINGUISHED | Solid point, own glow, pulses | Can be hovered, examined |
| SCOPED | Brightens inside Ref, dims outside | Same + scope indicator ring |
| WITNESSED | Stops flickering, holds steady | Can be referenced |
| GUARDED | Aura appears (green/red) | Can be evaluated |
| SEALED | All animation stops, permanent | Can be encountered as world content |

## BoundaryNode

Boundaries are not drawn by the player. They auto-spawn when two distinctions exist.
The world creates the relation. The boundary has its own clarity (average of endpoints
+ pair bonus) and solidifies when both endpoints are witnessed.

## RefRegion

A draggable spatial frame that defines scope. Distinctions inside are scoped (stable).
Distinctions outside are unscoped (flickering). Seeds CL-034.

## Aggregate clarity

The clarity bar reads `Events.get_aggregate_clarity()` — the average of all
distinction clarities. Not a stored value. A query. The world clarity is emergent
from its parts.

## Player experience

1. Click → a distinction appears. It flickers — tentative, barely real.
2. Click again → a second distinction + a boundary line between them. Both pulse.
3. The consequence card shows aggregate κ and distinction count.
4. Each distinction breathes on its own. They are alive, not static.
5. Future: scoping, witnessing, guarding, and sealing each distinction individually.
