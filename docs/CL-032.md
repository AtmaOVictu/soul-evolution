# CL-032 — Question Prompt + Consequence Card

## What this delivers

The player enters the Void. A question appears: **"What is different here?"**

The player clicks the field twice:
1. First click -> **CUT** distinction (kappa +0.10)
2. Second click -> **BOUNDED** distinction (kappa +0.15, boundary line drawn)

After each click, a **consequence card** slides in showing:
- What happened ("A distinction was made" / "A boundary exists")
- The kappa value and OntologyStage
- A dismiss prompt (click or Space)

After dismissal, the next question appears: **"Where is this true?"**

## Vocabulary

Never uses "correct" or "wrong". Uses: stable, witnessed, scoped, responsible.

## Architecture (layered)

| Layer | File | Role |
|-------|------|------|
| Event Bus | scripts/ritual/events.gd | Autoload singleton — all signals |
| State Machine | scripts/ritual/ritual_state_machine.gd | FSM spine — sequence control |
| Question | scripts/ritual/question_prompt.gd | RichTextLabel with typewriter + breath |
| Consequence | scripts/ritual/consequence_card.gd | Panel with slide-in/out tween |
| Clarity | scripts/ritual/clarity_bar.gd | ProgressBar with glow pulse |
| Field | scripts/ritual/distinction_field_ritual.gd | Click handler -> distinction events |
| Scene | scenes/ritual_loop.tscn | Integration of all above |

## Setup

1. **Register the Events autoload:**
   - Project Settings -> Autoload -> Add: scripts/ritual/events.gd as Events

2. **Open the scene:**
   - scenes/ritual_loop.tscn

3. **Run.** The ritual starts automatically. Click anywhere to make distinctions.
